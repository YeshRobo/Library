# Templates

Templates define the public v0 section-library surfaces.

Copy a template into the matching library folder, replace placeholder values, and keep paths repository-relative.

Recommended target folders:

- `section_seed_template.yaml` -> `library/sections/seeds/<section_slug>.yaml`
- `section_index_template.md` -> `library/sections/index/<section_slug>.md`
- `source_map_template.yaml` -> `library/sections/maps/<section_slug>.yaml`
- `brief_template.md` -> `library/sections/briefs/<section_slug>.md`
- `book_template.md` -> `library/sections/books/<section_slug>.md`
