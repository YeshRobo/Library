# Templates

Templates define the public v1 knowledge-target surfaces.

Copy a template into the matching library folder, replace placeholder values, and keep paths repository-relative.

Recommended target folders:

- `source_template.md` -> `library/knowledge/01_sources/<source_slug>.md`
- `artifact_template.md` -> `library/knowledge/02_artifacts/<source_slug>/artifact.md`
- `seed_template.yaml` -> `library/knowledge/03_seeds/<target_slug>.yaml`
- `target_index_template.md` -> `library/knowledge/04_targets/<target_slug>.md`
- `map_template.yaml` -> `library/knowledge/05_maps/<target_slug>.yaml`
- `brief_template.md` -> `library/knowledge/06_briefs/<target_slug>.md`
- `book_template.md` -> `library/knowledge/07_books/<target_slug>.md`
- `feedback_template.md` -> `library/knowledge/08_feedback/<target_slug>.md`
