# Sources

Sources preserve raw or lightly processed material that later artifacts, maps, briefs, and books can cite or synthesize.

A source should keep enough context for a reader to understand where later claims came from. Do not turn sources directly into books.

Current review sources:

- `library_layers_source.md` explains the earlier seven-layer model so maintainers can review what changed.
- `library_structure_design_source.md` proposes a target-centered Library structure update for the pipeline to evaluate.
