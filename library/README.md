# Library Root

This root holds source-grounded knowledge targets and their source-to-book pipeline surfaces.

Use:

- `knowledge/01_sources/` for raw or lightly processed material
- `knowledge/02_artifacts/` for compact source-derived draft artifacts
- `knowledge/03_seeds/` for proposed knowledge targets
- `knowledge/04_targets/` for accepted target-routing pages
- `knowledge/05_maps/` for gathered source and artifact membership by target
- `knowledge/06_briefs/` for required compact target memory
- `knowledge/07_books/` for optional long-form target books
- `knowledge/08_feedback/` for use feedback, contradictions, and revision triggers
- `templates/` for creating new surfaces

The library is a staged memory layer that turns source material into traceable briefs, books, and other knowledge outputs.

See `knowledge/01_sources/library_structure_design_source.md` for the proposed target-centered structure update source.
